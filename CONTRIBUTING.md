# Contributing to ChatWithIt

Thank you for your interest in contributing. ChatWithIt is a privacy-first, zero-backend AI chat platform — contributions that reinforce that mission are most welcome.

---

## Getting Started

```bash
git clone https://github.com/researchsociety1999-hub/Chat-With-It.git
cd Chat-With-It
npx serve .
# open http://localhost:3000
```

No build step. No package install required. Just serve and edit.

---

## What to Contribute

**High priority**
- Bug fixes
- Mobile UX improvements
- Accessibility improvements
- Performance optimizations
- Documentation improvements

**Welcome**
- New themes
- Prompt library additions
- Export format improvements
- Keyboard shortcut additions

**Please discuss first** (open an issue before starting)
- New providers or major API integrations
- Large UI redesigns
- New feature categories

---

## Pull Request Guidelines

1. Fork the repo and create a branch: `git checkout -b fix/your-fix-name`
2. Make your changes — keep them focused and minimal
3. Test in at least one browser
4. Open a PR using the provided template
5. Link the related issue if one exists

---

## Code Style

- Plain JavaScript — no frameworks, no bundlers
- Keep modules focused: `api.js` for API calls, `ui.js` for DOM, etc.
- No inline secrets, keys, or personal data — ever
- Prefer readable over clever

---

## Security

Do not include API keys, tokens, or credentials anywhere in your code or commit history. See [SECURITY.md](SECURITY.md) for the vulnerability disclosure process.
